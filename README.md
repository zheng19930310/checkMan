# 识别人类 - 性别年龄识别系统

这是一个基于PyTorch和OpenCV的实时人脸识别系统，能够通过电脑摄像头识别画面中人物的性别和年龄。

## 功能特性

- 🎥 实时摄像头捕捉
- 👤 人脸检测
- 🚻 性别识别（男/女）
- 🎂 年龄估计
- 🖥️ GUI界面显示
- ⏯️ 启动/停止控制
- 📊 实时FPS显示

## 环境要求

- Python 3.8+
- PyTorch 2.0+
- OpenCV 4.8+
- Pillow
- tkinter (Python内置)

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 方式1: GUI界面版本（推荐）

```bash
python main_gui.py
```

**功能说明：**
- 图形界面，易于操作


**功能说明：**

- 实时识别并显示结果

## 技术说明

本系统支持多种技术方案：

### 1. 深度学习方案
- **人脸检测**: 使用OpenCV的Haar Cascade或DNN模块
- **特征提取**: 基于预训练的ResNet18网络
- **性别分类**: 二分类问题（男/女）
- **年龄估计**: 回归问题

### 2. 预训练模型方案（推荐用于开发机）
- 使用OpenCV DNN模块加载预训练模型
- 轻量级，适合开发测试
- 不需要强大的GPU

## 常见问题

**Q: 为什么识别结果不准确？**
A: 当前版本使用的是简化算法。建议使用预训练的深度学习模型，如：
- 性别识别: 使用在大规模人脸数据集上训练的模型
- 年龄估计: 使用回归模型在标注数据集上训练

**Q: 如何提高识别准确率？**
A: 
1. 使用预训练的深度学习模型
2. 确保光线充足
3. 保持摄像头清晰
4. 人脸正对摄像头

**Q: 可以在开发机上运行吗？**
A: 可以！GUI版本专为开发机设计，使用轻量级算法，不需要高性能GPU。
